## 5. INSTRUKSI IMPLEMENTASI GOOGLE SITES
Karena Google Sites membatasi eksekusi JavaScript kustom, desain (Glassmorphism, Hover state) diwujudkan sepenuhnya menggunakan CSS.

**Langkah Implementasi:**
1. Di halaman Google Sites, pilih opsi **Sematan (Embed)**.
2. Pilih tab **Sematkan Kode (Embed Code)**.
3. Salin seluruh isi dari file `landing-page-embed.html` yang telah saya buat di proyek ini.
4. Paste kode tersebut ke dalam kotak, lalu klik **Berikutnya** dan **Sisipkan**.
5. Sesuaikan lebar frame embed agar memenuhi layar penuh (Full Width).

Kode HTML/CSS telah mencakup:
- Import Font Inter otomatis dari Google Fonts.
- CSS Variables untuk warna.
- Efek Hover (scale, box-shadow) murni menggunakan CSS.
- Responsivitas penuh untuk perangkat seluler.
